# Линейная алгебра

## Матрицы

### Ранг матрицы

Ранг — максимальное число линейно независимых строк (или столбцов) матрицы. Ранг по строкам всегда равен рангу по столбцам.

Считать удобно методом Гаусса: приводим матрицу к ступенчатому виду, ранг равен числу ненулевых строк.

### Определитель

Определитель квадратной матрицы равен нулю тогда и только тогда, когда её строки линейно зависимы. Геометрически модуль определителя — во сколько раз линейное отображение меняет объём.

det(AB) = det(A) · det(B). При перестановке двух строк знак определителя меняется.

### Обратная матрица

Обратная матрица существует только для квадратной матрицы с ненулевым определителем. Находить её проще всего методом Гаусса: приписываем справа единичную матрицу и приводим левую часть к E.

## Собственные значения

Собственный вектор v матрицы A — ненулевой вектор, для которого Av = λv. Число λ — собственное значение.

Собственные значения — корни характеристического многочлена det(A − λE) = 0.

У симметричной матрицы все собственные значения вещественные, а собственные векторы для разных λ ортогональны. На этом держится PCA: ковариационная матрица симметрична.

## SVD

Любую матрицу можно разложить как A = UΣVᵀ, где U и V ортогональные, а Σ диагональная с неотрицательными сингулярными числами.

Если оставить k наибольших сингулярных чисел, получится лучшее приближение матрицы ранга k. Это используется для сжатия и в рекомендательных системах.
