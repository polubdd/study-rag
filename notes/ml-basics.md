# Основы машинного обучения

## Переобучение

Переобучение — модель запомнила обучающую выборку вместо закономерности: на train ошибка маленькая, на тесте большая.

Что помогает: больше данных, регуляризация (L1/L2), упрощение модели, ранняя остановка, кросс-валидация для честной оценки.

## Кросс-валидация

Данные делятся на k фолдов, модель обучается k раз, каждый раз один фолд используется для проверки. Итоговая метрика — среднее по фолдам.

Для временных рядов обычный KFold нельзя: модель будет учиться на будущем. Используют TimeSeriesSplit.

## Метрики классификации

Precision — какая доля предсказанных положительных действительно положительные. Recall — какую долю настоящих положительных модель нашла.

F1 — гармоническое среднее precision и recall. Accuracy бесполезна при сильном дисбалансе классов.

## Градиентный бустинг

Ансамбль деревьев, где каждое следующее дерево обучается на ошибках (антиградиенте) предыдущих. На табличных данных обычно сильнее нейросетей. Популярные реализации: CatBoost, LightGBM, XGBoost.
