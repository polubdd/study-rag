# Программирование на Python

## Типы данных

### Изменяемые и неизменяемые

Неизменяемые типы — int, float, str, tuple, frozenset: операция над ними создаёт новый объект. Изменяемые — list, dict, set: их можно менять на месте.

Поэтому нельзя использовать список как значение по умолчанию в аргументе функции: он создаётся один раз и общий для всех вызовов.

### Словари

Словарь — хеш-таблица: поиск по ключу в среднем за O(1). Ключом может быть только хешируемый объект, поэтому список ключом быть не может, а кортеж — может.

## Функции

### Генераторы

Генератор — функция с yield: значения вычисляются по одному, по запросу, и не хранятся в памяти целиком. Подходит для больших файлов и бесконечных последовательностей.

### Декораторы

Декоратор — функция, которая принимает функцию и возвращает новую, с дополнительным поведением: логирование, кэширование, проверка прав. Пример из стандартной библиотеки — functools.lru_cache.

## Сложность алгоритмов

Сортировка в Python (Timsort) работает за O(n log n). Поиск элемента в списке — O(n), в множестве — O(1) в среднем.

Бинарный поиск по отсортированному массиву — O(log n): каждый шаг отбрасывает половину.
