# Теория вероятностей

## Условная вероятность

P(A|B) = P(AB) / P(B), если P(B) > 0.

События независимы, если P(AB) = P(A) · P(B). Попарная независимость не означает независимость в совокупности.

### Формула Байеса

P(A|B) = P(B|A) · P(A) / P(B).

Классический пример: тест на редкую болезнь. Даже при точности теста 99% большинство положительных результатов ложные, если болезнь встречается у 0.1% людей. Всё решает априорная вероятность P(A).

## Случайные величины

### Математическое ожидание и дисперсия

E[X + Y] = E[X] + E[Y] — всегда, даже для зависимых величин.

D[X] = E[X²] − (E[X])². Для независимых D[X + Y] = D[X] + D[Y].

### Нормальное распределение

Плотность симметрична относительно среднего. Правило трёх сигм: в интервал μ ± 3σ попадает примерно 99.7% значений.

## Предельные теоремы

Закон больших чисел: среднее выборки сходится к математическому ожиданию.

Центральная предельная теорема: сумма большого числа независимых одинаково распределённых величин с конечной дисперсией приближённо нормальна. Поэтому доверительные интервалы для среднего строят через нормальное распределение.
